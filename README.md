# AeroBlade

## 🎮 Game Description

The player controls a character in a Minecraft-themed world.  
Move and shoot enemies while surviving waves of mobs.  
The game is top-down and features multiple levels with increasing difficulty.


![Player](shoot%27em%20up/shoot%27em%20up/Assets/Player.png)

## 🕹️ Controls

| Action | Key |
|------|----|
| Move | Z Q S D |
| Shoot | Space |

## 🗺️ Levels

The game has **4 levels**.  
- To progress to the next level, you must **defeat the boss** at the end of the current level.  
- Each level features **different types of enemies**.  
- The final levels include **stronger and more challenging enemies**.
